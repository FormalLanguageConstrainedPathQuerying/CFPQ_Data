*****
MCFPQ
*****

.. only:: html

   :Release: |release|
   :Date: |today|

Multiple context-free path queries (MCFPQ) constrain the paths of a labeled
graph by a multiple context-free language, generated by a multiple
context-free grammar (MCFG). An MCFG nonterminal of arity :math:`k` denotes
:math:`k` independent paths simultaneously; the start symbol always has arity
one, so reachable pairs are defined exactly as for CFPQ. The graph catalog is
shared across all query classes — the "Applicable graphs" list below
cross-links the per-graph pages without duplicating them.

MCFG templates are stored in the ``.mcfg`` Datalog-like format, documented in
the :ref:`FLPQ design <flpq>` and read by
:obj:`mcfg_from_text <flpq_data.queries.mcfpq.readwrite.mcfg.mcfg_from_text>`.
No MCFG templates have been added yet; they arrive together with the data, so
this section has no template pages.
